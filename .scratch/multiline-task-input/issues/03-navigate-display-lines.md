# 03: 按显示行移动光标

**What to build:** 用户可以跳到当前显示行首尾，也可以沿同一屏幕列上下移动，定位长草稿中的编辑位置。

**Blocked by:** 01 长草稿自动折行，输入框随内容伸缩

**Status:** ready-for-agent

- [x] 在自动折出的第二行分别按 Ctrl+A 和 Ctrl+E，光标落在该行首字符之前和末字符之后；通过插入文字验证位置。
- [x] ↑/↓ 每次移动一个显示行，在长行、短行、长行之间连续移动时先停在短行末尾，再恢复原目标列。
- [x] 在首行向上或末行向下时光标留在原处；在中文、组合字符和表情附近移动时光标落在完整字符边界。
- [x] 通过现有 TUI 模型在自动折行草稿上验收按键、屏幕光标和编辑结果，可独立于 02 完成。
