# 02: Ctrl+J 在光标处换行，Enter 提交整份草稿

**What to build:** 用户可以在插入点分开前后文字、添加空行，再把整份多行草稿作为一个任务提交。

**Blocked by:** 01 长草稿自动折行，输入框随内容伸缩

**Status:** ready-for-agent

- [x] 在“你好”和“世界”之间按 Ctrl+J，两段文字分行显示，光标位于“世界”之前，编辑操作不发送任务。
- [x] 再次按 Ctrl+J 后中间出现一个空行；在已有自动折行的草稿上也可插入真实换行。
- [x] 通过现有 TUI 模型按 Enter，在允许提交时仅发出一个任务请求，正文逐字保留主动插入的换行。
- [x] 现有粘贴行为保持兼容，覆盖单行粘贴及终端控制字符过滤的回归测试通过。
