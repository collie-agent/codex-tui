# 01: 长草稿自动折行，输入框随内容伸缩

**What to build:** 用户输入长任务时可以看到连续的显示行，并能在有限的终端高度内继续编辑和提交原文。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 从一行开始输入中英文与表情混排的草稿，超过可用宽度后按终端列宽折行，组合字符和表情保持完整。
- [ ] 输入框随行数增高，达到终端可用高度的一半后在框内滚动；光标始终可见，极小的非空终端仍保留编辑位置。
- [ ] 删除文字或调整窗口宽度后重新排版并相应收缩或增高，光标仍对应草稿中的同一插入位置（删除操作按编辑结果定位）。
- [ ] 从现有 TUI 模型发送输入和尺寸事件，检查视图与光标；按 Enter 后捕获任务请求，确认正文与草稿原文一致。
