# 03: 浏览历史输出与恢复自动跟随

**What to build:** 用户可以向上浏览正在输出的任务历史、拖选复制文本，并通过“回到底部”回到实时输出；终端缩放后仍能正常阅读。

**Blocked by:** 01 — 接入已有任务，显示流式文本与完成状态。

**Status:** ready-for-agent

- [x] 默认跟随新输出；用户向上滚动后暂停跟随，后续事件不抢走阅读位置。
- [x] 暂停跟随时显示可点击的“回到底部”，点击后定位最新内容并恢复跟随。
- [x] 滚动范围始终有效；内容不足一屏时没有无效偏移，底部输入区和状态栏不随历史滚动。
- [x] 支持输出文本的正向和反向鼠标拖选、Ctrl+C 复制，保留 Unicode 完整字符与原有复制语义。
- [x] 可见内容、选择高亮、复制和鼠标命中使用一致的布局；滚动或缩放不会复制到已经失效的屏幕位置。
- [x] 新流式输出到达时，历史阅读和文本选择行为保持一致，不将选择错误映射到其他文本。
- [x] 终端缩放后正确重排长行，保持合理阅读位置；极窄、极矮及零尺寸窗口不越界。
- [x] 使用 TUI 消息与可控 SSE 覆盖持续输出期间滚动、暂停跟随、返回底部、拖选复制和缩放；沿用现有 Unicode、布局和剪贴板测试风格。
- [ ] 在交互终端验证滚动、点击、选择和光标，运行 Go 测试与静态检查。

## Notes

不依赖创建入口，因此可直接用已有任务演示。本票提供工具结果展开所需的历史阅读和鼠标交互基础。
