# 03: 复用助手文本排版，并限制缓存内存

**What to build:** 长会话中已完成的助手文本无需反复解析 Markdown，当前流式响应及时更新，反复刷新和缩放不导致派生缓存无限增长。

**Blocked by:** 02 — 共享布局，减少事件更新中的重复渲染。

**Status:** ready-for-agent

- [x] 按助手文本身份、内容版本和可用宽度复用 Markdown 与换行结果；未变化历史不再因每次刷新重新解析全部正文。
- [x] 流式更新优先仅使当前助手文本排版失效，允许重排整个当前响应，正确处理跨增量的 Markdown 结构变化。
- [x] 覆盖内容替换、历史加载、任务和代理视图切换、工具调用区展开状态变化及缩放后的正确显示，避免缓存串用或陈旧结果。
- [x] 派生缓存具有明确容量上限和淘汰行为，不永久保存每个内容版本或窗口宽度的副本；淘汰不删除原始正文且内容仍可重新显示。
- [x] 固定历史下反复流式更新、刷新及切换宽度，验证回收后的存活堆有界，区分正文与缓存占用。
- [x] 在 Update → View 边界验证纯文本、复杂 Markdown、中文及表情的显示和复制，并按 01 的预算记录性能对比；不以内部缓存结构作为行为断言。
