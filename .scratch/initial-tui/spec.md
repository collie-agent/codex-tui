# 初始 TUI 布局与文本选择

Status: ready-for-agent

## Problem Statement

用户需要一个可运行的终端界面，复现已提供的 Codex 初始界面参考图，并能验证布局、基础输入和文本复制体验。当前仓库已初始化 Go 模块并添加界面相关依赖，但尚无应用代码或测试。

## Solution

使用 Bubble Tea 实现全屏初始界面：顶部显示标题、版本及工作目录，中间保留空白，底部固定灰色输入区和彩色状态栏。保持参考图的英文文案与深灰配色，随终端尺寸调整布局。展示数据固定，输入可编辑但不发送。用户可拖动鼠标选择界面文本，按 Ctrl+C 复制纯文本，按 Ctrl+D 退出。

## User Stories

1. As a 终端用户, I want 启动后看到完整的初始界面, so that 我能直接验证布局效果。
2. As a 终端用户, I want 看到参考图中的标题与版本, so that 界面具有一致的识别信息。
3. As a 终端用户, I want 看到实际工作目录, so that 我知道程序运行的位置。
4. As a 终端用户, I want 中间区域保持留白, so that 初始界面与参考图一致。
5. As a 终端用户, I want 输入区固定在底部, so that 我能稳定地找到输入位置。
6. As a 终端用户, I want 状态栏位于输入区下方, so that 我能查看模型与用量信息。
7. As a 终端用户, I want 看到固定的模型、推理等级和额度, so that 我无需连接服务即可预览界面。
8. As a 终端用户, I want 空输入时看到英文提示, so that 我能识别输入区的用途。
9. As a 终端用户, I want 输入和删除文本, so that 我能验证基础编辑体验。
10. As a 终端用户, I want 按 Enter 时暂不发送内容, so that 当前原型保持在布局验证范围内。
11. As a 终端用户, I want 调整窗口时布局适应新尺寸, so that 界面仍然可用。
12. As a 窄屏终端用户, I want 输入区优先保持可用且状态信息截断显示, so that 长状态文案不会破坏布局。
13. As a 终端用户, I want 用鼠标拖动选择界面文字, so that 我能指定要复制的内容。
14. As a 终端用户, I want 选择标题、路径、输入内容及状态栏文字, so that 复制能力覆盖主要界面区域。
15. As a 终端用户, I want 按 Ctrl+C 将选区复制到系统剪贴板, so that 我能在其他应用中粘贴。
16. As a 终端用户, I want 复制结果仅包含纯文本, so that 内容不会夹带颜色或终端控制序列。
17. As a 终端用户, I want 无选区时 Ctrl+C 不执行操作, so that 我不会意外退出或修改剪贴板。
18. As a 终端用户, I want 按 Ctrl+D 退出, so that 我有明确且独立的退出快捷键。

## Implementation Decisions

- 使用 Bubble Tea；现有依赖已包含 Bubble Tea v2、Lip Gloss v2 及 ANSI 文本处理工具。
- 全屏展示，顶部标题与目录、中间弹性留白、底部输入区与状态栏形成一个整体布局。
- 固定标题为 OpenAI Codex，版本为 v0.165.0；目录取实际工作目录。
- 保留参考图的英文文案、深灰背景、灰色输入区及彩色状态文本；按终端字符网格还原布局。
- 固定展示 GPT-6.1 Terra medium、0 in、weekly 88% left、5h 100% left；不查询真实模型或额度。
- 空输入提示为 Ask Codex to do anything。支持输入、删除；Enter 暂不发送。
- 响应终端尺寸变化；窄屏优先维持输入区可用，状态栏过长时截断。
- 应用管理鼠标拖动选区，范围覆盖标题、路径、输入内容及状态栏；选区必须可辨识。
- Ctrl+C 有选区时复制纯文本到系统剪贴板，无选区时不执行操作；Ctrl+D 退出。
- 将界面状态、事件处理与渲染组织在应用级交互边界内。剪贴板写入作为外部效果，不让测试修改真实剪贴板。
- 剪贴板传输方式尚未锁定；实现需说明终端或系统依赖，不能仅发出复制指令就声称剪贴板已验证成功。

## Testing Decisions

- 建议采用一个主要测试边界：应用级事件输入 → 可见界面和外部效果。测试不绑定内部字段、辅助函数拆分或完整 ANSI 输出字节。
- 用户已确认该测试边界；产品需求与测试方案均已达成共识。
- 覆盖初始渲染、窗口缩放、窄屏截断、输入与删除、Enter 不发送以及 Ctrl+D 退出。
- 以鼠标按下、拖动、释放和 Ctrl+C 的事件序列验证选区与复制内容，覆盖正反方向、跨行、中文及宽字符，确保复制无样式控制序列。
- 验证无选区的 Ctrl+C 不退出、不写剪贴板；验证有选区的 Ctrl+C 不退出。
- 自动化测试观察复制请求的纯文本载荷；在实际支持的终端中手动验证粘贴结果及退出后的终端恢复。
- 以参考图人工核对配色、间距和上下区域位置；不做依赖字体像素的截图强比较。
- 当前仓库没有既有应用或测试案例可复用；不为渲染细节逐层新增测试边界。

## Out of Scope

- 模型服务调用、真实额度查询、模型切换与推理等级切换。
- 发送消息、生成回复、对话历史、流式响应和工具执行。
- 多行编辑器、命令菜单、会话持久化和配置系统。
- 复制样式或图片，以及与参考图字体像素完全一致的渲染。
